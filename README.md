# Khazna AI MVP — Support Analytics Platform

AI-Powered Customer Support Analytics built with Next.js 15, Supabase, and OpenAI.

## Stack
- **Frontend:** Next.js 15 (App Router) + Tailwind CSS + shadcn/ui
- **Backend:** Supabase (PostgreSQL + Auth + RLS)
- **AI:** OpenAI GPT-4
- **Integrations:** Freshchat (webhooks + API polling)
- **Deployment:** Vercel

## Features
- Dark theme (Khazna-style)
- Supabase authentication
- Freshchat conversation sync (webhooks + polling + manual)
- OpenAI conversation analysis
- KPI dashboard
- Audit workflow (approve/reject AI results)
- Vercel cron job (every 5 min)
